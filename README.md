# Python Exercises

Welcome to this Python learning repository! Here you'll find a comprehensive collection of 40 practical exercises designed to help beginners and young programmers master the fundamentals of Python programming.

## 📚 Repository Structure

```
python-excercises/
├── README.md                    # This file
├── Exercises.md                 # Complete list of all 40 exercises
├── Learning Program.md          # Learning program guide
└── Exercises/                   # Exercise files
    ├── exercise01.py           # Hello World
    ├── exercise02.py           # Personal message
    └── ...                     # 40 exercises total
```

## 🎯 About This Repository

This repository contains a structured learning program with 40 hands-on Python exercises organized into 8 progressive categories:

1. **Basic I/O & Variables** (Exercises 1-5) - Learn to print, get input, and work with variables
2. **Arithmetic Operations** (Exercises 6-10) - Master calculations and mathematical operations
3. **Conditionals** (Exercises 11-15) - Make decisions with if/else statements
4. **Loops** (Exercises 16-20) - Repeat actions with for and while loops
5. **Lists** (Exercises 21-25) - Work with collections of data
6. **Functions** (Exercises 26-30) - Create reusable code blocks
7. **Turtle Graphics** (Exercises 31-35) - Draw shapes and create visual programs
8. **Advanced Projects** (Exercises 36-40) - Build complete applications

## 📋 Getting Started

1. **Clone this repository:**
   ```bash
   git clone https://github.com/KidsHacking/python-excercises.git
   cd python-excercises
   ```

2. **View the exercises:**
   - See [Exercises.md](Exercises.md) for a complete list of all 40 exercises with descriptions
   - Check [Learning Program.md](Learning%20Program.md) for the learning program guide

3. **Start coding:**
   - Navigate to the `Exercises/` folder
   - Open any exercise file (e.g., `exercise01.py`)
   - Read the exercise description in [Exercises.md](Exercises.md)
   - Write your solution!
